# Claude Chat (Android)

## Выпуск версии (Termux, не Debian) — одним блоком

Репозиторий на GitHub: `Nugggets/claudechat` (создать пустым, если его ещё нет). Архив скачать в «Загрузки», затем в Termux:

```
mkdir -p ~/claudechat && cd ~/claudechat
unzip -o ~/storage/downloads/ClaudeChat-v1_7.zip
grep -c 'versionName = "1.7"' app/build.gradle.kts
[ -d .git ] || { git init -b main && git remote add origin https://github.com/Nugggets/claudechat.git; }
git add -A
git commit -m "1.7"
git pull --no-rebase -X ours --no-edit
git push -u origin main
```

`grep` должен вывести `1`. При самом первом запуске `git pull` напишет ошибку про ветку — это нормально. После `push` GitHub Actions соберёт APK, он появится в Releases как `ClaudeChat-vX.Y.apk` и установится поверх старой версии (подпись всегда одна и та же).

Для новой версии: в блоке заменить номер в имени архива, в `grep` и в `git commit`.

## Что это

Простой чат с Claude на телефоне. Приложение шлёт запросы на `POST {адрес}/v1/messages` с вашим ключом и показывает ответ по мере генерации.

- Вложения (📎): фото из галереи, снимок с камеры, PDF, текст и код (любые текстовые файлы), docx и pptx (текст извлекается), zip-архивы (список файлов и текст всех текстовых файлов внутри, до 300 тыс. символов). До 10 файлов в одном сообщении; фото сжимаются до 1568 px, PDF до 25 МБ.
- «Поделиться» из других приложений: файлы, фото и текст можно отправить в Claude Chat через системное меню «Поделиться».
- Голосовой ввод (🎤) через системное распознавание речи.
- Правка и удаление своих сообщений, «Поделиться» и «Удалить» для ответов.
- Меню чата (⋮): переименовать, отдельная инструкция для чата, поделиться, сохранить в файл .md, скопировать весь чат, удалить.
- История: поиск по названиям и тексту, сохранение всех чатов в один файл, «Удалить все».
- Кнопка «Загрузить список моделей с сервера» в настройках (запрос `/v1/models`): нужна, если прокси называет модели иначе. Быстрый выбор модели: нажать на строку с моделью и токенами.
- Настройки: температура (необязательно), веб-поиск Claude (только официальный API).
- Автоповтор запроса (до двух раз) при перегрузке сервера или лимите.
- Оформление ответов: заголовки, жирный, курсив, цитаты, код, списки.
- Настройки: адрес API (по умолчанию `https://api.anthropic.com`), ключ, способ передачи ключа (`x-api-key` или `Bearer`), модель, лимит токенов ответа, системная инструкция, размер текста 10–32, тёмная и светлая тема.
- Кнопка «Проверить ключ» делает маленький запрос и показывает, работает ли ключ.
- Счётчик потраченных токенов (вход и выход) вверху экрана чата.
- История чатов, копирование ответа, «Повторить», остановка генерации.
- Ключ хранится в зашифрованном виде (Android Keystore) и уходит только на указанный адрес.

Модели: `claude-opus-5-5`, `claude-fable-5-1`, `claude-sonnet-5-5`, `claude-haiku-5-5`.

## Структура

- `app/src/main/java/com/nugggets/claudechat/`
  - `MainActivity.kt` — экран чата, отправка, потоковый приём
  - `SettingsActivity.kt` — настройки и проверка ключа
  - `HistoryActivity.kt` — список чатов
  - `Api.kt` — запрос к API (SSE-поток и обычный ответ), понятные ошибки
  - `Files.kt` — приём вложений (фото, PDF, текст, docx, pptx, zip) и экспорт чата
  - `Store.kt` — настройки, шифрование ключа, хранение чатов и вложений
  - `Md.kt` — простое оформление ответа (заголовки, жирный, код, списки)
  - `Ui.kt` — цвета и общие элементы
- `app/build.gradle.kts` — версия (`versionName`, `versionCode`)
- `.github/workflows/build.yml` — сборка APK и публикация в Releases
- `app/claudechat.jks` — ключ подписи APK (один и тот же, чтобы обновления ставились поверх)

Внешних библиотек нет: только стандартный Android SDK.

## Заметки

- Адреса с `http://` Android блокирует, нужен `https://`.
- Таблицы xlsx сначала сохраните как CSV и прикрепите как текстовый файл.
- Вложения хранятся на телефоне вместе с чатом и уходят в API при каждом запросе, пока сообщение с ними есть в чате (это входные токены). Ненужные файлы удаляйте вместе с сообщением.
- Репозиторий лучше держать приватным: в нём лежит ключ подписи APK.
- Если сборка в Actions упала, открыть вкладку Actions, последний запуск, и прислать текст ошибки.

## История версий

- 1.0 — первая версия.
- 1.1 — вложения (фото, камера, PDF, текст, код, docx, pptx), «Поделиться» из других приложений, голосовой ввод, правка и удаление сообщений, меню чата, поиск и экспорт истории, температура, веб-поиск, автоповтор при перегрузке, курсив и цитаты.
- 1.2 — загрузка списка моделей с сервера (исправляет ошибку «Invalid model name» на прокси).
- 1.3 — прикрепление zip-архивов.
- 1.4 — улучшена поддержка zip-архивов (определение по MIME-типу, фильтрация бинарных файлов, отображение структуры архива) и обновлён интерфейс.
- 1.5 — живая индикация действий ИИ в реальном времени (подготовка, отправка, размышления, инструменты, печать ответа с секундомером), предпросмотр распакованных вложений по нажатию, автосклейка подряд идущих сообщений при повторе после ошибки.
- 1.6 — кнопка «🐞 Диагностика» (в верхней панели, в меню чата, в карточке ошибки и в настройках) для копирования полного технического отчёта одним нажатием.
- 1.7 — встроенный сборщик проектов и ZIP-архивов прямо из ответов ИИ (`Builder.kt`): ИИ знает о возможности отдавать готовые ZIP-файлы, приложение автоматически объединяет изменённые файлы с исходным архивом (включая `.jks` ключи подписи и ресурсы), сохраняет готовый ZIP в «Загрузки» одним нажатием (`📦 Скачать ...zip`), показывает список изменённых файлов (`📂 Файлы`) и кнопку копирования команды Termux (`💻 Скопировать команду Termux`). Добавлена поддержка таблиц `.xlsx` и увеличен лимит токенов по умолчанию до 16384.
- 2.3 — оформление как в приложении Claude (тёплая палитра, терракотовый акцент, ответы без пузыря с шрифтом с засечками, светлая и тёмная темы); системная инструкция по умолчанию с тоном и манерой Claude (её можно изменить в настройках), в запрос добавляется текущая дата; история: автобэкап Android (чаты и вложения восстанавливаются после переустановки через аккаунт Google), кнопки «Копия для восстановления» и «Восстановить из копии» (JSON), атомарная запись файлов чатов, предупреждение о нечитаемых чатах.
- 2.4 — пустой ответ модели (поток с message_start и message_stop без текста) больше не даёт ошибку про JSON: приложение сообщает причину и автоматически повторяет запрос до двух раз; кнопки в карточке ошибки видны на тёмной теме, «🐞» вместо длинной подписи.
- 2.5 — при пустом потоковом ответе запрос повторяется без стриминга (видна настоящая ошибка прокси); в диагностике показывается реальная версия приложения; стандартная системная инструкция применяется и на старых установках, где поле было пустым.
- 2.6 — отступ сверху («заглушка») для экранов с неработающей верхней частью сенсора: по умолчанию 72 dp у верхней панели всех экранов, регулируется в настройках («Вид»), 0 — без отступа.
- 2.7 — максимально близко к общению с Claude: развёрнутая системная инструкция (характер, тон, длина и форма ответов, честность, эмоциональные темы, границы); поле «О себе» (память) отправляется с каждым запросом; переключатель «Расширенное размышление»; лимит ответа по умолчанию 16384 (старые 4096 поднимаются автоматически).
- 2.8 — ближе к приложению Claude: нумерованные списки и маркированные с выравниванием, зачёркнутый текст, таблицы Markdown выводятся выровненным текстом, приветствие «Чем могу помочь?» на пустом чате, автоназвание чата по первому ответу.
- 2.9 — автопамять (Claude сам ведёт заметки о вас, их можно править в настройках); под ответом с блоками кода появились кнопки «копировать», «сохранить в Загрузки» и «▶ Открыть» для HTML/SVG во встроенном браузере.
- 3.0 — качество ответов: служебная добавка сборщика проектов отправляется только в разговорах про проекты и файлы; блок «💭 Размышления» вырезается из истории перед отправкой; длинный разговор автоматически сворачивается в краткое содержание (вложения из начала сохраняются); кеширование промпта на официальном API.
