# GorodWatcher v0.3

Все функции внутри приложения (Termux больше не нужен для работы):

- **Лента** — база найденных записей, поиск, карточка (карта/фото), «Проверить сейчас».
- **Монитор** — фоновый мониторинг новых записей (служба с уведомлением), интервал, окно дней, уведомления Android и Telegram (токен бота + chat id), тест, настройки батареи.
- **Данные** — загрузка всей истории с даты, статистика, экспорт в CSV (Download/gorod_*.csv).
- **Сайт** — WebView gorod.mos.ru с «Скачать дамп» (диагностика).

Первый запуск мониторинга на пустой базе только запоминает записи (без спама); галка «Уведомлять и о записях первой загрузки» включает уведомления и для них.
Чтобы мониторинг не убивала система: «Батарея» -> разрешить работу без ограничений.

tools/ — старые скрипты для Termux, приложению не нужны.

## Обновление из Termux (одним блоком)

    cd ~/gorodwatcher; unzip -o ~/storage/downloads/GorodWatcher-vX_Y.zip; grep -c "WorkService" app/src/main/AndroidManifest.xml; git add -A; git commit -m "vX.Y"; git pull --no-rebase -X ours --no-edit; git push

Дальше Actions собирает APK, он появляется в Releases (тег latest).
